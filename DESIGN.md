# Проектные решения (DESIGN.md)

## 1. Отмена устаревших запросов (`AbortController`)

Для защиты от гонки ответов (race condition) в модуле `src/search.ts` хранится ссылка на текущий `AbortController`. При каждом изменении поля ввода (`input(value)`) вызывается `controller.abort()` **сразу в момент ввода**, а не только после срабатывания `debounce`.

**Почему не флаг «актуальный ли запрос»?**
Флаг лишь игнорирует устаревший ответ уже после его скачивания, но браузер продолжает держать соединение и загружать данные из сети. Вызов `AbortController.abort()` прерывает HTTP-запрос на уровне браузера (`canceled` во вкладке Network).

В `src/search.ts` в блоке `catch` разделяются два типа прерывания:

- `DOMException` с `name === 'AbortError'` — запрос отменён самим приложением при новом вводе; ошибка пользователю не показывается.
- `DOMException` с `name === 'TimeoutError'` — сработал `AbortSignal.timeout(5000)` из `src/api.ts` (скомпонованный через `AbortSignal.any`); пользователю выводится сообщение об ошибке и кнопка «Повторить».

## 2. Выбор задержки `debounce` (300 мс)

Задержка в **300 мс** выбрана как баланс между скоростью отклика интерфейса и экономией сетевых запросов:

- **Если убрать задержку (`0 мс`):** каждый символ вызывает сетевой запрос и его немедленную отмену, создавая лишнюю нагрузку на API и частое мигание индикатора загрузки.
- **Если сильно увеличить (`1000+ мс`):** поиск ощущается медленным и не похожим на живой поиск по мере ввода.

## 3. Вычислительная сложность (Big O)

Для функции `mapCountryResponse(raw)` в `src/mapper.ts`:

- **По времени:** $O(L + C)$, где $L$ — количество языков страны, $C$ — количество валют. Так как на практике число языков и валют одной страны невелико (ограничено константой), обработка одной записи занимает амортизированное $O(1)$, а списка из $N$ стран — $O(N)$.
- **По памяти:** $O(L + C + B)$, где $B$ — длина массива граничащих стран (`borders`), так как формируется новый нормализованный объект `Country`.

## 4. Принципы чистого кода в проекте

- **Разделение логики и DOM:** вся работа с сетью (`src/api.ts`), маппингом (`src/mapper.ts`), задержкой (`src/debounce.ts`) и состоянием поиска (`src/search.ts`) не зависит от браузерного DOM и тестируется в Node.js. Отрисовка изолирована в `src/render.ts`.
- **Чистые функции:** `mapCountryResponse` (`src/mapper.ts`) не изменяет входные данные и не имеет побочных эффектов.
- **Безопасная работа с DOM:** в `src/render.ts` и `src/main.ts` не используются `innerHTML` и `insertAdjacentHTML`; элементы создаются через `document.createElement` и заполняются через `textContent`.
